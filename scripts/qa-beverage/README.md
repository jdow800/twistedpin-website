Offline browser QA for real BeverageCost/TapInventory components. No upstream proxy, live API, menu write, email, or paid replay.

Run `node scripts/qa-beverage/serve.mjs`, then in another terminal `node scripts/qa-beverage/run.mjs`. Uses the existing COGS isolated headless Chrome driver (`COGS_QA_CHROME` overrides its browser binary). Checks 360/412/1280 widths, explicit zero, save/reopen, review/submit once, unmatched all-in cost remaining unknown, and kitchen-link conflicts. The kitchen scenario checks both count-detail destinations and walk ranges, a concurrent revision returning 409, failed reload retaining the selected counts and reason, successful reload using the fresh revision while retaining the reason, and explicit confirmation before the retry. Screenshots/results are regenerable ignored artifacts in output/.
